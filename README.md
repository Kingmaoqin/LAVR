# LAVR: Local Action-Value Readout for Diffusion Language Models

Code for *Towards Value-Aware Unmasking: Local Action Value in Diffusion Language Models* (under review, anonymous submission).

LAVR tests whether the frozen hidden states of a diffusion language model encode how much each candidate unmasking decision is worth. For every candidate commitment `a` in a recorded decoding state `s`, it estimates the policy-relative advantage `A^π(s,a) = Q^π(s,a) − V^π(s)` from matched forced and reference rollouts that share common random numbers. Targets and features are centred within each candidate set. Linear readouts on frozen hidden states are then compared against output and trajectory controls.

This repository holds only the core implementation and the benchmark definitions. Collected labels, hidden-state shards and results are not included. They are regenerated by the scripts below.

## Layout

```

  nemotron_policy.py      block/confidence-threshold decoding for Nemotron
  collect.py              state snapshots, candidate sets, paired rollouts (Path-LL)
  collect_task.py         task-correctness action labels (GSM8K / SVAMP)
  features.py             output / trajectory / distributional controls (C1-C3)
  data.py, dataset.py     OpenWebText windows, shard loading, document-level splits
  probes.py, stats_suite.py  two-block ridge readouts, metrics, cluster bootstrap
scripts/                  collection and primary analyses

  rlib/                   probe / metric / statistics library used by analysis/
  toy_exact.py            production estimators vs exact DP on an enumerable toy DLM
  synthetic_tests.py      probe-family self-tests with known-answer labels

```

## Benchmarks

| Study | Backbone | Population | Target |
|---|---|---|---|
| Global state value | Nemotron-Diffusion-3B | GSM8K test, first 800 problems (4,411 states) | rollout success `V^π(s)` |
| Local Path-LL action value | MDLM-169.6M (ancestral, confidence), SEDD-169.6M | 400 OpenWebText windows per condition; fresh replication; K = 64 ranking study | per-token and downstream Path-LL advantage |
| Task-correctness action value | Nemotron-Diffusion-3B | GSM8K batches C (180) and D (570), SVAMP (200) | correctness advantage |

The exact settings are in [benchmarks/populations.json](benchmarks/populations.json). Datasets and checkpoints are downloaded from the Hugging Face Hub (`openai/gsm8k`, SVAMP, `stas/openwebtext-10k`, and the model IDs listed there).

## Setup

```bash
pip install -r requirements.txt
```

The MDLM/SEDD experiments were run with PyTorch 2.7.0+cu126 and Transformers 4.53.2. The Nemotron loader needs Transformers >= 5.0.0, so put it in a separate environment.

## Reproduce

```bash
bash benchmarks/run_path_ll.sh       # MDLM / SEDD Path-LL action value
bash benchmarks/run_state_value.sh   # Nemotron global state value
bash benchmarks/run_task_action.sh   # Nemotron task-correctness action value
```

Label shards are written to `data/labels_<tag>/` and results to `results/` and `analysis/results/`. Each script accepts `--help`, and the collection scripts take `--offset`/`--n_prompts`, so large collections can be split across GPUs.

## Evaluation rules built into the code

- Splits are made at the document or prompt level. Candidates and states from one document are never split across folds.
- The two-block ridge includes `γ = 0` in its grid, so the hidden-augmented readout nests the control-only baseline.
- Layers and hyperparameters are chosen on validation data only. Uncertainty comes from prompt/document-cluster bootstrap.
- Falsification controls are included: shuffled global state, Gaussian replacement and label permutation. So are split-half label-reliability ceilings.
- `analysis/toy_exact.py` checks the production estimators against exact dynamic programming. `scripts/pipeline_selftest.py` checks that the readouts recover a planted signal and do not report one when none is planted.
